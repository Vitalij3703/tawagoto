## Tawagoto
Tawagoto is a small OS, made for old x86_32 machines. Specifically, laptops. <br>
Tawagoto was made using no AI, excepts for really repetitive stuff (the shiftmap in the PS/2 keyboard driver).<br>
There are no future plans bringing Tawagoto to other architectures.

# Install
To install/compile Tawagoto, you must first execute 'compile.sh'. <br>
The resulting ISO, ELF, OBJ files will be in 'build/' <br>
If you don't know which file is the ELF one, it is 'tg.bin'.
<br>
Compiling it also executes 'run.sh', which emulates the OS in QEMU.
